## AI 使用规则

- 先按学科、出版社、册次和目录标题匹配，不根据学科名称猜版本。
- 没有页码证据时只返回章节或课次，不编造页码。
- 英语“第 119 页 Starter Unit One”和地理任务必须等待封面、目录或原图确认。
- 作业确认前只生成建议；只有用户确认教材档案后，作业才写入已确认教材关系。
