# @deepseek-ai/dsh-education-homework-controller

[English](README.md) | 中文

## 概述

这个 Host 包负责保存每日作业和教材档案，并提供教育工作台使用的 Remote 方法。它预设七年级上册数学、语文、历史和生物学章节索引；英语标记为待核对封面，地理不自动选定版本。`analyze` 先在本地解析老师原文，再通过 `ctx.agentDefaultModel` 调用 DSH LLM 服务；即使本地解析器没有识别出科目标题，也会让智能体根据完整消息识别科目和任务，并补充教材引用和摘要。模型和规则都会保留 `requiresParentAssistance`，在所属学科的作业行中标记签字、检查、听孩子讲解或家长辅导等附加要求；改错与给家长讲解等并列动作会保存为同一学科下的两个任务，成绩说明等背景通知不会作为可执行作业保存。所选提供方失败或返回无效内容时，控制器在有可用规则结果时保留规则任务，并把真实提供方错误返回到确认页。`coach` 请求分步提示，也提供相同的规则兜底。

## 使用本包

在 Web App Host 组合中与 storage、LLM 和默认模型服务一起加载本包。浏览器通过生成的 Remote 调用 `getToday`、`listHistory`、`analyze`、`confirmImport`、`updateTaskStatus`、`saveTextbook`、`coach`、`getChapter`、`analyzeChapter` 和 `updateChapterProgress`。`listHistory` 返回按日期倒序的完成统计，历史详情仍通过 `getToday(dateKey)` 读取，因此可以按天回看并筛选未完成日期。

章节学习记录保存在独立的 `chapters` 表中，与每日作业日期解耦。`analyzeChapter` 要求调用方提供确认过的课文原文，并保存原文指纹、结构化分析、引用提示和学习进度；原文变化后应重新生成分析。对已收录的公版课文，`getChapter` 会在首次打开或补读旧的缺正文记录时自动写入正文，再由客户端自动生成章节分析；其他教材仍需用户提供正文。

同一天的学科计时会保持单课独占：启动一门新课时，其他正在计时的课程自动暂停并保留已用时；离开作业页面是否停止当前计时由客户端先征求确认。

## 模型体验

### 作业整理、辅导与章节学习

#### 模型看到的内容

整理请求包含完整老师原文和已保存教材档案；模型可以直接返回科目和任务标题，因此没有学科标题的自然语言消息也能进入确认流程。控制器会把模型任务补齐为统一的作业记录，并保留保守置信度和教材匹配状态。辅导请求包含一道作业标题及其匹配教材标题。章节学习请求包含用户确认的课文原文、教材元数据和章节索引，要求模型返回概览、结构、重点句、复述提纲和分层练习，并为具体判断提供原文依据。控制器要求整理和章节分析返回一个 JSON 对象，会兼容思考标签、代码围栏等常见模型包装，并在首次仅格式不兼容时重试一次。调用直接使用选定的 DSH LLM 路由，不创建持久 Agent 会话，也不开放工具。

#### Token 影响

每次整理、辅导或章节分析发起一次提供方请求，输入 token 随老师原文、课文原文和教材档案文本增长；章节分析会把用户确认的正文作为主要输入。

#### KV Cache 影响

控制器不选择缓存键，也不持久化提供方缓存状态。

## 已知限制与延期工作

- **没有持久 Agent 会话**：模型调用没有对话历史、工具执行或自主追问。
- **教材匹配保持保守**：模型可以建议教材引用，但持久化前仍需在确认流程中选择已保存的教材档案。
- **章节资料由用户提供**：当前纵向流程支持粘贴或上传 `.txt/.md`，尚未接入图片 OCR、PDF 提取或外部 RAG。
