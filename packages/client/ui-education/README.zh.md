# @deepseek-ai/dsh-client-ui-education

[English](README.md) | 中文

## 概述

这个浏览器插件为 DSH Web 增加教育工作台：把整段老师群消息粘贴进来，检查保守的科目和任务识别结果，确认后将当天作业持久化到 Host，并在“今日作业”中按学科跟踪完成状态；“历史作业”支持按日期回看每日完成统计，并可只看仍有未完成项的日期；“预习 / 复习”支持先选科目、再选教材课次进入章节学习页。进入某科“开始写作业”后，作业清单下方会以左侧课文原文、右侧分析结果的双栏方式展示匹配课次；没有保存原文时，左侧会明确提示资料缺口，右侧仍可显示基础参考。原文没有给出的信息会明确显示为待补充，不会自动编造。

本包只负责作业闭环，不替换 DSH 的 Conversation、流式传输或 Agent Runtime。在没有配置适配器之前，也不虚构 Moodle 或 RAGFlow 数据。

## 使用方式

点击“添加模型”会直接打开 DSH 标准的“模型”弹窗，可添加兼容模型，并将其目录中的一个模型保存为全局默认。配置可用模型后，打开“添加作业”，粘贴完整消息，选择“开始整理”，检查拆出的任务，再选择“确认加入今日作业”。Host 作业控制器会把原文与已保存的教材档案发送给默认模型，即使消息没有明确的学科标题，也会先让智能体根据上下文识别科目和任务；请求失败时才回退规则解析，并显示提供方返回的真实错误。

“教材档案”页面预设了数学、语文、历史和生物学的七年级上册章节索引，并保留来源链接。英语必须先核对封面和页码，地理不自动选择版本。每个预设都会把章节索引交给模型用于建议，但不会凭空生成页码。

点击“新增教材”后可在弹窗中填写教材信息并上传 `.pdf`、`.txt` 或 `.md`。文本 PDF 会在浏览器本地提取文字，自动生成 Markdown 预览并可下载；保存教材档案时只保存教材元数据、目录索引和文件名，不会把整本教材内容塞进每日作业记录。

打开语文目录中的章节后，页面会先展示通行版本的基础参考（概览、内容梳理、结构、主题和关键词），无需额外操作即可阅读；预习和复习共用章节资料，已有 AI 内容直接复用，没有时可上传或粘贴确认过的课文原文，再调用默认模型生成基于原文的概览、内容梳理、主题、重点句、复述提纲和分层练习。分析结果与学习进度独立持久化；模型失败时显示保守的原文分段兜底，并保留真实警告。

## Model Experience

### 教育作业工作台

#### What the model sees

浏览器展示层本身不发起模型请求。Host 作业控制器在辅助整理时发送完整老师消息与已保存的教材档案，在辅导时发送所选任务标题及其匹配教材标题；打开章节后，发送用户确认的课文原文、教材元数据和章节索引，要求生成概览、结构、重点句、复述提纲和分层练习。整理与章节分析要求返回 JSON，辅导要求返回分步提示。

#### Token effect

每次整理、辅导或章节分析发起一次提供方请求。输入大小随老师消息、课文原文和教材档案文本增长。

#### KV Cache effect

无。本包不组装模型上下文，也不改变提供方缓存键。

## Known Limitations and Deferred Work

- **直接调用模型，不是 Agent 会话**：整理与辅导会使用 DSH LLM 服务及全局默认模型，但尚未创建带工具、历史和自主追问能力的持久 Agent 会话。
- **延期集成**：Moodle、RAGFlow、提醒和家长账号等待明确的服务契约与部署信息。
- **章节资料范围**：新增教材支持文本 PDF、`.txt` 和 `.md` 的本地整理；扫描版 PDF 需要 OCR，图片 OCR、整本教材的独立文档存储和跨章节检索仍未接入。
